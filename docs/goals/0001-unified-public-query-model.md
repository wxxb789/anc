# 0001 — Unified public query model

Status: superseded. Created: 2026-09-13. Split: 2026-09-14.

This goal originally combined the public SQLite projection, static relationships,
browser previews, tag queries, graph exploration, publication gates, packaged
adoption, and performance acceptance into one completion judgment. Those outcomes
can be verified separately. Keeping this umbrella active would duplicate their
completion contracts.

The original intent remains required for 0.1.0. Its complete replacement is:

- [0002 — Consistent static relationships](archive/0002-consistent-static-relationships.md)
- [0003 — Reliable lazy previews](archive/0003-reliable-lazy-previews.md)
- [0004 — Complete tag browsing](archive/0004-complete-tag-browsing.md)
- [0005 — Interactive graph exploration](archive/0005-interactive-graph-exploration.md)
- [0006 — Safe release output](archive/0006-safe-release-output.md)
- [0007 — Independent publisher adoption](0007-independent-publisher-adoption.md)
- [0008 — Acceptable browser cost](0008-acceptable-browser-cost.md)

The [goal index](README.md) maps the original scope to these outcomes. The original
100/1,000/10,000-note workload, mobile p95 target, cold-preview comparison, and
resource-policy acceptance now belong to 0008. Schema, semantics, and architecture
remain in [core design](../core-design/README.md).

This goal was **not completed** and must not move to the completed-goal archive.
Its number is retained and will not be reused. No successor is completed merely
because these goal files exist.
